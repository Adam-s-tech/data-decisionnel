# Démo · du fichier au tableau de bord

> Démo générique sur données fictives. Aucun fichier client.

## Données

Le fichier `LAB-ventes.csv` contient 12 lignes : mois, région, produit, chiffre d'affaires, marge, commandes.

## Parcours de démonstration

1. Charger le fichier et vérifier les types de colonnes.
2. Construire un tableau croisé par mois et par région.
3. Ajouter deux indicateurs : chiffre d'affaires et marge.

La capture `assets/capture-tableau-de-bord.svg` montre le rendu attendu.

## Ce que la démo ne contient pas

- Aucune donnée client.
- Aucune formule métier.
- Aucun modèle de rapport.
